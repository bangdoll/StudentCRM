# 架構決策記錄 (Architecture Decision Record)

## ADR-003: 學員專屬 Learning Hub 與教練零密碼通行門禁架構

### 背景與問題
1. 蔡教練擁有數百堂一對一教學紀錄，需交付給學員高品質、免記帳密的專屬複習空間。
2. 避免公開網域直接暴露全體學員名冊與 CRM 後台數據（隱私防護）。
3. 確定學員結業後或暫停上課時之連結有效性規範。

### 決策內容

1. **教練端通行（Coach Passkey Gate: /coach/zzzz）**：
   - 採用與學員完全相同的「專屬密鑰連結」體驗，廢除傳統使用者名稱與密碼輸入表單。
   - 蔡教練透過私鑰網址 `/coach/zzzz` 一秒直通後台，系統設置 180 天 Session Cookie，支援 iPhone PWA 加入主畫面秒開。
   - 未經授權之訪客直接訪問根目錄 `/`、`/student/*` 或 `/api/*` 一律回傳 HTTP 403 並渲染 `templates/lock.html` 隱私保護頁。

2. **學員端學習空間（My Learning Hub: /my/{token}）**：
   - 採用無感 Token 專屬連結（Magic Pass），以學生之 UUID 進行 100% 視野隔離。
   - 學員僅能查看自身歷次課堂筆記、八堂修煉技能樹 (Skill Tree) 與課堂 3 張微行動卡。
   - 若學員竄改網址嘗試訪問首頁或他人頁面，立即觸發 403 門禁攔截。

3. **結業存取權限模型：方案 3（終生課堂資產庫模式）**：
   - 學員已完成之堂數與筆記永久開放存取，不設過期攔截。
   - 視為學員終生持有之付費數位學習資產，未續約時不再增加新堂數。
   - 極大化個人品牌口碑、轉介紹與學員好感度。
