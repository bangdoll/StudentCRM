# PRD：第一堂數位管理課自動建立 StudentCRM 個人頁面

日期：2026-10-06

## 目標

當教學同步流程讀取 Google Calendar 快取，且事件標題代表「第一堂數位管理教學」時，若 StudentCRM 尚無同名學員，就建立一筆最小必要的個人學員資料，讓個人專屬頁面可以使用。

## 長期規則

1. 觸發條件包含：數字格式 `01.學員數位管理教學`，或語意格式 `學員第一堂數位管理教學`、`第一堂數位管理教學：學員`。
2. 事件必須能解析出明確學員姓名；只有標題本身沒有姓名時，才跳過建檔並保留待人工確認。
3. 已存在同名或別名學員時，保留原學員 ID、原私密 Token 與原頁面，不重複建立。
4. 新建學員必須產生穩定 ID、第一堂日期與高熵英文私密 Token，專屬頁面只允許完整 Token 網址讀取。
5. 規則只由教學同步流程執行；單純 GET 讀取頁面不得產生建檔副作用。

本次以 `01.Liya數位管理教學` 驗收。

## 允許範圍

- 新增 Liya 的 StudentCRM 個人資料。
- 同步 `StudentCRM/data/students.json` 與 `OpenClaw/Data/students.json`。
- 在既有 `sync_teaching_records_to_crm` 流程加入第一堂事件的建檔規則。
- 新增單元測試與本次驗收文件。

## 禁止事項

- 不覆蓋或刪除原始教學筆記。
- 找不到原始筆記時不虛構教學內容。
- 不修改既有學員資料。
- 不讓單純 GET 讀取頁面產生資料寫入副作用。

## 完成條件

- Liya 具有穩定 UUID5 ID `806fac9e-6139-54e0-a774-75f87fc0202e`。
- 個人入口使用高熵英文 Token；只有完整網址持有人可以讀取。
- 兩份本地學員 SSOT 完全一致。
- 第一堂日曆事件可自動建立新學員，重複同步不重複建立。
- `Liya第一堂數位管理教學`、`第一堂數位管理教學：Amy` 等語意格式可自動辨識；無姓名的標題不建檔。
- 測試通過，且 Vercel 部署達到 READY。

## 驗收清單

- [x] 新增 Liya 前已建立快照。
- [x] Diff 僅新增 Liya 與規則程式碼／測試／文件；既有蘋果總裁班資料變更保留不碰。
- [x] `data/students.json` 與 `OpenClaw/Data/students.json` 通過 `cmp -s`。
- [x] Liya 私密個人頁讀回成功；數位管理詳情路由仍受管理門禁保護。
- [x] 可猜測的 UUID 入口回傳 404。
- [x] 找不到教學筆記時不虛構內容，讀回筆記數為 0。
- [x] Vercel deployment 狀態為 READY，生產健康檢查與私密頁 HTTP 200。

## 停止條件

- 學員資料筆數異常縮水。
- 兩份 SSOT 不一致。
- 測試失敗且原因未定位。
- 部署未達 READY。
